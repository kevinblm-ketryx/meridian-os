# meridian-os

Embedded Linux image for the Meridian device (Yocto-style layer).

Fake sample component for the Meridian release-manifest → Ketryx demo.
Nothing here builds or runs; it exists so the repo has tagged releases whose
commit SHAs can be pinned per Ketryx version.

Releases are recorded in `kevinblm-ketryx/meridian-releases`.
